# Opportunity Compass 🧭

A responsive web application designed to help students and job seekers discover and explore opportunities such as internships, jobs, scholarships, and skill-development programs through a clean, organized, and user-friendly interface.

## 🌐 Live Demo

https://sachinsrawat.github.io/opportunity-compass/

## ✨ Features

- **Explore Opportunities:** Browse different opportunities for academic and professional growth.
- **Internship Listings:** Discover internship opportunities to gain practical experience.
- **Job Opportunities:** Explore available job opportunities.
- **Scholarship Discovery:** Find scholarship opportunities to support education.
- **Search Functionality:** Find relevant opportunities easily.
- **Category Filtering:** Browse opportunities based on different categories.
- **Responsive Design:** Works across desktop, tablet, and mobile screens.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 How to Run Locally

1. Clone this repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the Live Server extension.
4. Start exploring opportunities.

## 🎯 Project Purpose

Opportunity Compass aims to simplify the process of discovering career and educational opportunities by bringing relevant listings together in one accessible platform.

The project demonstrates practical front-end development skills, including DOM manipulation, event handling, responsive UI design, and interactive web development.
